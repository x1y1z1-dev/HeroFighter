# План HeroFighter

Оновлено: 2026-10-29

## Готово

- [x] Каркас: Vite + TypeScript (strict) + Phaser 3.90
- [x] Генератор ассетів (спрайт-листи 3 персонажів + фон арени) без сторонніх бібліотек
- [x] Екран завантаження, головне меню, екран вибору бійця, екран керування
- [x] Три режими: `1 vs 1`, `гравець проти бота`, `бот проти бота`
- [x] Боєць: стан-машина (idle/walk/jump/block/attack/hit/ko), автоповорот, хітбокси, хітстун, відкид
- [x] Дві атаки (рука/нога) з фазами startup/active/recovery
- [x] Унікальні атаки на персонажа (дані в `attacks.ts` + `characters.ts`)
- [x] Блок із зменшенням шкоди до 15 %
- [x] **Розведені клавіші атак**: P1 `G`/`H`, P2 `5`/`6` (цифровий ряд + Numpad)
- [x] **Обмін ударами** (обидва хітбокси в одному кадрі) + подвійне KO як нічия
- [x] **Hit-stop** на влучанні (80 мс, 45 мс блок, 180 мс KO)
- [x] **Процедурний звук** через WebAudio + `M` для вимкнення
- [x] Бот: дискретні плани, реакція на атаку, покарання промахів, три рівні складності
- [x] **Бот використовує платформи**: переслідує суперника вгору, стрибає на платформу з кута
- [x] HUD: смуги HP із «чіп»-затримкою, таймер, піпси раундів, оголошення
- [x] Раунди до 2 перемог, нічия за таймером, екран результату з реваншем
- [x] Пауза (`ESC`) з оверлеєм
- [x] Typecheck + продакшн-збірка проходять
- [x] Workflow для GitHub Pages

## Наступні кроки (за пріоритетом)

1. **Контент**
   - [ ] 1–2 нові персонажі (палітра + стати + власні атаки)
   - [ ] Друга арена та вибір арени
   - [ ] Супер-удар із зарядом
2. **Бій**
   - [ ] Input buffer 120 мс (натиск під час recovery не губиться)
   - [ ] Parry: блок у вікні ~100 мс → 0 шкоди + довший блокстан атакуючого
   - [ ] Комбо-лічильник і скейлінг шкоди
   - [ ] Блок-стан окремою анімацією + «слайд» назад
   - [ ] Air-juggle обмеження (щоб не було нескінченних комбо)
3. **Бот**
   - [ ] Прогноз позиції замість поточної (стрибок на випередження)
   - [ ] Адаптивна складність за рахунком
   - [ ] Навчання на діях гравця (запис і відтворення)
4. **Мобільні/геймпад**
   - [ ] Touch-кнопки для телефону
   - [ ] Gamepad API для другого гравця
5. **Якість**
   - [ ] Юніт-тести на `resolveAttack`/хітбокси (Vitest, чиста логіка без Phaser)
   - [ ] ESLint + Prettier у CI

## Відомі обмеження

- Платформи суцільні: зіскочити вниз крізь них не можна (тільки з краю).
- Бот не планує стрибок на платформу заздалегідь — реагує на позицію суперника.
- Звук синтетичний, без музики.
