# HeroFighter

Двобійний файтинг на **Phaser 3 + TypeScript + Vite**. Три режими: локальний `1 vs 1`, гравець проти бота та бот проти бота (режим для тестування взаємодії персонажів).

Усі графічні ассети генеруються скриптом — у репозиторії немає сторонніх бінарників і проблем з ліцензіями.

## Швидкий старт

```bash
npm install
npm run dev        # http://localhost:5173
```

Інші команди:

| Команда | Що робить |
| --- | --- |
| `npm run dev` | dev-сервер з HMR |
| `npm run build` | `tsc --noEmit` + продакшн-бандл у `dist/` |
| `npm run preview` | локальний перегляд зібраної гри |
| `npm run typecheck` | лише перевірка типів |
| `npm run assets` | перегенерувати спрайти та фон у `public/assets` |

## Керування

| Дія | Гравець 1 | Гравець 2 |
| --- | --- | --- |
| Рух | `A` / `D` | `←` / `→` |
| Стрибок | `W` | `↑` |
| Блок | `S` | `↓` |
| Удар рукою (швидкий) | `G` | `5` (або Numpad `5`) |
| Удар ногою (сильніший) | `H` | `6` (або Numpad `6`) |
| Пауза | `ESC` | `ESC` |
| Звук вкл/викл | `M` | `M` |

Блок зменшує шкоду до 15 %, але не дає рухатись. Боєць автоматично розвертається до суперника.

Клавіші атак розведені по різних руках: P1 бʼє `G`/`H` (права рука на WASD), P2 — `5`/`6` (права рука на стрілках). Обидва гравці можуть тримати блок і бити, не тягнучись через усю клавіатуру.

## Правила бою

- 100 HP, 60 секунд на раунд, бій до 2 перемог (максимум 3 раунди).
- Удар рукою: 6 шкоди, швидкий; удар ногою: 11 шкоди, повільніший, сильніший відкид.
- Після закінчення часу перемагає той, у кого більше HP; за рівності — нічия.
- **Обмін ударами**: якщо обидва хітбокси активні в одному кадрі, обидва удари проходять (trade). Одночасний KO — нічия в раунді.
- Кожен персонаж має власні `speed`, `jump`, `power` (множник шкоди) та `defense` (множник отриманої шкоди).

## Персонажі

| Персонаж | Стиль | Особливість |
| --- | --- | --- |
| KAI | збалансований | базові удари, гарний старт |
| RIN | швидка | найшвидші удари; удар ногою — ривок уперед (lunge 240) |
| BRUTUS | важкий | повільні удари, +20 % шкоди, найсильніший відкид |

Атаки описані даними в `src/data/attacks.ts` (база) + `attacks` у `src/data/characters.ts` (модифікатори персонажа). Кожен удар має фази `startup → active → recovery` у мс, тому баланс не залежить від FPS.

## Відчуття бою

- **Hit-stop**: при влучанні обидва бійці завмирають на 80 мс (45 мс при блоці, 180 мс при KO) — удар «читається».
- **Звук**: повністю процедурний (WebAudio, `src/audio/Sfx.ts`) — удари, блок, стрибок, KO, дзвін раунду. Жодних аудіофайлів. `M` — вимкнути/увімкнути.

## Структура проєкту

```
index.html
src/
  main.ts                 # конфіг Phaser, реєстрація сцен
  config/game.ts          # розміри, фізика, правила, профілі ботів
  data/
    attacks.ts            # база ударів + resolveAttack (модифікатори персонажа)
    characters.ts         # ростер, стати, унікальні атаки
    animations.ts         # карта кадрів + реєстрація анімацій
    stage.ts              # геометрія арени (мусить збігатись з артом)
  objects/Fighter.ts      # стан-машина бійця, хітбокси, шкода
  ai/BotController.ts     # бот: плани, реакція, складність, платформи
  audio/Sfx.ts            # процедурний WebAudio-синтез
  input/controller.ts     # Intent + клавіатурні біндинги
  scenes/                 # Boot, Menu, Select, Controls, Fight
  ui/                     # HUD, кнопки
  utils/assets.ts         # шлях до assets з урахуванням BASE_URL
tools/gen-assets.mjs      # генератор спрайтів і фону (єдине джерело арту)
public/assets/            # згенеровані PNG
docs/                     # план, опис спрайтів
```

## Деплой на GitHub Pages

`vite.config.ts` має `base: './'`, тому збірка працює з будь-якої підтеки. Готовий workflow: `.github/workflows/deploy.yml` — запуш у `main`, і GitHub Actions збереже `dist/` на Pages (у налаштуваннях репозиторію: *Settings → Pages → Source: GitHub Actions*).
